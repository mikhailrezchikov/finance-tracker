# Finance Tracker

Консольное приложение для учёта доходов, расходов и бюджетов. Данные пользователей сохраняются в `data/finance-tracker.bin` и восстанавливаются при следующем запуске.

## Запуск

Нужны Java 17 и Maven:

```bash
mvn package
java -jar target/finance-tracker-1.0-SNAPSHOT.jar
```

После запуска зарегистрируйтесь или войдите в существующую учётную запись. Категории с пробелами указывайте в двойных кавычках.

## Как пользоваться

1. Создайте пользователя командой `register` или войдите через `login`.
2. Создайте категории расходов: например, `category add Еда`.
3. Добавляйте доходы и расходы командами `income` и `expense`.
4. При необходимости задайте лимит расходов для категории через `budget`.
5. Выполните `report`, чтобы увидеть суммы по категориям и остаток бюджета.
6. Завершите работу командой `exit` — данные сохранятся автоматически.

Для подсказки в самом приложении используйте команду `help`.

## Примеры использования

### Учёт доходов, расходов и бюджета

```text
register ivan password
category add Еда
income Зарплата 50000
expense Еда 1200
budget Еда 4000
report
exit
```

### Выборочный отчёт и экспорт в файл

```text
report Еда
report Еда file food-report.txt
```

Первый вызов выводит данные только по категории `Еда` в терминал, второй сохраняет их в `food-report.txt`.

### Перевод другому пользователю

Получатель должен быть предварительно зарегистрирован:

```text
transfer maria 500
```

У отправителя перевод фиксируется как расход, а у пользователя `maria` — как доход.

## Команды

| Команда | Описание |
| --- | --- |
| `register <логин> <пароль>` | Регистрация и вход |
| `login <логин> <пароль>` / `logout` | Вход и выход из профиля |
| `category add <название>` / `category list` | Создать или показать категории расходов |
| `income <категория> <сумма>` | Добавить доход |
| `expense <категория> <сумма>` | Добавить расход |
| `budget <категория> <сумма>` | Установить бюджет категории |
| `report [категория ...] [file <путь>]` | Вывести отчёт в терминал или файл |
| `transfer <логин> <сумма>` | Перевести средства другому пользователю |
| `save` / `exit` | Сохранить данные / сохранить и завершить работу |

## Как протестировать код

Запуск всех тестов:

```bash
mvn test
```

Полная сборка с тестами и отчётом о покрытии:

```bash
mvn clean verify
```

Проверка стиля кода (Checkstyle):

```bash
mvn checkstyle:check
```

Рекомендуемый порядок перед коммитом:

```bash
mvn checkstyle:check && mvn clean verify
```

После тестов отчёт о покрытии доступен в `target/site/jacoco/index.html`.

Те же проверки выполняются в CI (`.github/workflows/ci.yml`) при push и pull request в `main`.
